# Interface Archaeology

An interactive museum of the interfaces, objects, and tiny rituals that technology left behind.

**[Visit the live museum →](https://shadman-a.github.io/interface-archaeology/)**

Products rarely disappear all at once. First, a button becomes a gesture. A card becomes a setting. A familiar sound becomes silent background infrastructure. **Interface Archaeology** documents those transitions and asks whether the replacement was actually better.

## On view

The first exhibition contains nine recently departed artifacts:

- The removable SIM
- The screensaver
- The TiVo grid
- The 59th/63rd Street secret transfer
- The airplane cabin projector
- The iPod click wheel
- The notification LED
- The corporate email signature
- The big-box software package

Each exhibit records what replaced the artifact, what improved, and what quietly disappeared with it.

## Run locally

```bash
npm install
npm run dev
```

Open the local address printed in your terminal.

## Build

```bash
npm run build
```

The project is built with React, TypeScript, Vite, and CSS. The collection is static, fast, keyboard-accessible, responsive, and requires no backend.

Every push to `main` builds and deploys the site through GitHub Pages.

## Add an artifact

Artifacts live in `src/Museum.tsx`. Add an entry to the `artifacts` array, choose or create a specimen treatment, and submit a pull request.

A good nomination is not merely old. It should represent a transition: something that used to make an invisible system understandable, tactile, communal, or strange.
